Entry for the [Ridiculous at First Glance, Real by the Second](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a)
bounty on make.fun — one sentence pitching a bizarre startup idea that
sounds ridiculous at first glance but makes sense as a real business.

## The pitch

> Let us press your voicemail onto vinyl for $50 — grandparents pay because a message they can hold beats a grandchild they can't reach.

## How it works

`main.py` (Python 3, standard library only) validates the sentence — one
line, exactly one sentence, 1–200 characters, no control characters — and
writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR` /
`$ENTRY_OUTPUT_DIR` when set) with mode 0644 so the grader can read it.

## Run

```sh
python3 main.py
```
